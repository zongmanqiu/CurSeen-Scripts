CurSeen Lua 脚本 API 速查 + 虚拟键盘方案 JSON（供 AI 助手参考，随包分发）
适用 CurSeen 2.1.0（LUA_API 3）。速查在每次发送时现读；缺失会明确告知，不要臆造 API。
========================================================

## 总体模型
- 脚本 = UTF-8 的 .lua 文件。个人脚本放进 `assets/lua` 的**角色目录**即被扫描；
  保存后约 250 ms 热加载，面板开着也会自动刷新，无需重启。
- **归属只看目录**（脚本里没有任何字段能改变挂载点）：
  - `assets/lua/MouseTrail/` 拖尾特效（role="effect"）：每帧 `step(dt)` + `draw(ctx)`；
  - `assets/lua/HoverDot/` 悬浮标（role="effect" 同款契约，可用 `ctx:image`）；
  - `assets/lua/ClickFx/` 点击特效（role="effect" 同款契约，还收 `on_press`）；
  - `assets/lua/KeySound/` 击键音效（role="keysound"，键盘页专属，不走脚本页）；
  - `assets/lua/scripts/` 通用扩展（role 缺省 "composite"）：声明 `menu` 时进入贴图右键「脚本」
    子菜单，否则只在脚本页「运行」；入口 `run(ctx, params)`，返回字符串自动弹结果框。
- **官方/在线包**安装在 `assets/lua/scripts/<id>/`：`pack.json` + 平铺脚本与同目录资源 + `info/`；
  与个人脚本同一条扫描/热加载链路，升级整包替换、不碰别的包。
- 键音脚本（`assets/lua/KeySound/`）：入口 `run(ctx, params)`，ctx 里有 `sounds`（候选名数组）、
  `key`、`mods`、`repeated`、`dt`；返回 `sounds` 的文件名或 1 起索引 → 播放它；返回 `false`
  → 强制静音；返回 `nil` / `true` / 其它 → 落回默认音。老式
  `on_key(key, mods, repeated, params)` 返回同样的语义。
- 顶层全局：
  - effect：`effect_name`（显示名）、`name`、`description`、`schema()`、`defaults()`（老式）、
    `init`、`on_move`、`on_press`、`on_mouse_down`、`on_mouse_up`、`on_wheel`、`step`、`draw`；
  - composite / run 类：`name`、`description`、`role`、`menu`、`category`、`requires`、
    `schema()`、`run(ctx, params)`；
  - 通用可选：`category`（mouse / picture / text / ai 排序）、`requires`
    （相对脚本目录的外置文件；缺一个就不进右键菜单）。
- v2 包的 `pack.json`（由打包工具生成，一般不手写）：
  `id` / `name` / `version` / `layout: 2` / `files`（包内全部相对路径，逐一一致）/
  `category` / `single`（单脚本包直接出普通卡片）/ `api`（所需 Lua API 级别，高于宿主则置灰）/
  `min_host`（宿主最低版本）。升级是整包替换；包内 `info/{LICENSE,README.md,HISTORY.md}`
  必须齐全，至少一个 `.lua`。

## 运行环境与硬规则（错一条就会“完全没效果”）
- 标准库**只有** `base` / `table` / `string` / `math` / `package`；**没有**
  `io` / `os` / `debug` / `coroutine` / `utf8`。不要写 `os.time` / `os.clock` / `os.date` /
  `io.*`；真实时间用 `wall_ms` / `local_ms` / `unix_ms`。
- **`init()` 没有参数**：不要在 `init` 里读 `params`（它是 nil，会直接报错）。
  需要默认值就在 `init` 里写常量；`params` 只在带参回调里用（宿主已合并 schema 默认值）。
- **`step(dt, t, params)` 没有 `ctx`**；所有 `ctx:*` 只能写在 `draw(ctx, params)` 里。
- 想实现“指针静止 N 秒后出现/变化”：必须让 `draw` 持续收到帧——**`draw` 返回正整数毫秒**
  （例如 `return 100`）；悬浮标静止后宿主会停帧，不返回就永远等不到下一步。
  静止时长用 `wall_ms`（真实时间）算，`elapsed` 只适合动画相位。
- `cursor_hover` 是“系统正在给出交互光标提示”（I 形/手形/缩放…），**不是**“鼠标停在
  窗口上/静止了多久”。静止检测请用 `wall_ms - last_move_ms`。
- 跨帧状态用脚本全局变量或 upvalue（如 `still_ms = wall_ms - last_move_ms`），
  不要只在 `draw` 里用局部变量。
- 颜色助手返回值个数：`hex_to_rgb -> r,g,b,a`（4 个）；`hsv_to_rgb -> r,g,b`（**只有 3 个**，
  没有 alpha）；多接一个会得到 nil，传给 `ctx` 会报错。

## 环境变量（effect 每帧可读）
`screen_w` / `screen_h`（虚拟屏尺寸）、`screen_x` / `screen_y`（虚拟屏原点，可为负；
整屏暗罩/星空/镜像中心要用它）、`elapsed`（秒；只适合动画相位，不能测“距事件多久”）、
`wall_ms`（系统运行毫秒，休眠也推进；静止检测/超时淡出用它）、`local_ms`（本地 Unix 毫秒）、
`unix_ms` / `tz_offset_min`、
`cursor_x` / `cursor_y`（指针位置；点击效果里 = 按下点）、`mouse_x` / `mouse_y`（旧别名）、
`cursor_vx` / `cursor_vy` / `cursor_speed` / `cursor_heading`（60fps 每帧像素 / 弧度）、
`mouse_vx` / `mouse_vy` / `mouse_speed` / `mouse_heading`（CursorFX 别名）、
`mouse_down`（bool）、`mouse_button`（"left"/"right"/"middle"/"x1"/"x2"）、
`cursor_hover`（bool：系统正在给出交互光标提示——I 形/手形/缩放/禁止/帮助/十字；
桌面按钮仍是箭头，所以它不代表“指针下有按钮”）、
`origin_x` / `origin_y`（实例出生点）、`host`（"trail" / "hover" / "clickfx" / "panel"）、
`_params`（参数表）。

## 全局函数
- `hex_to_rgb("#RRGGBB" 或 "#RRGGBBAA") -> r,g,b,a`（0–255；8 位顺序 R,G,B,A；6 位返回 a=255）
- `rng(min, max) -> float`、`rng_int(min, max) -> int`（整数闭区间；空/非法区间安全返回 min）
- `clamp(v, min, max)`、`lerp(a, b, t)`（t 自动钳 0..1）
- `hsv_to_rgb(h, s, v) -> r,g,b`（h 度、s/v 0..1、返回 0..255 整数）
- `play_sound(file, volume?)`：播音效（volume 0..100）。`file` 可为面板 `file` 参数挑的
  路径，或 `assets/Sounds` 里的裸名（如 "click3"）。★ **仅 role="composite"（host="panel"）**
  的实例注入；其它角色调用会报「找不到全局」。`run` 的返回值不会发声，必须显式调它。

## 绘图 ctx 方法（draw(ctx, params)）
颜色一律 0..255 整数分量；坐标为逻辑坐标（窗口自动处理 DPI / 多屏平移）。
`circle` / `rect` 画**实心**；要描边用 `ring` / `line` / `polygon` 自己拼。
- `ctx:circle(x, y, r, cr, cg, cb, alpha)` —— 实心圆
- `ctx:ellipse(x, y, rx, ry, cr, cg, cb, alpha)` / `ctx:ellipse_ring(x, y, rx, ry, thickness, ...)`
- `ctx:round_rect(x, y, w, h, radius, ...)` / `ctx:round_rect_ring(x, y, w, h, radius, thickness, ...)`
- `ctx:ring(x, y, r_outer, thickness, cr, cg, cb, alpha)` —— 圆环（thickness ≥ 外径退化成实心）
- `ctx:rect(x, y, w, h, cr, cg, cb, alpha)`
- `ctx:line(x1, y1, x2, y2, thickness, cr, cg, cb, alpha)`
- `ctx:polygon(pts, cr, cg, cb, alpha)`（普通混合）/ `ctx:fill_polygon(pts, cr, cg, cb, alpha)`
  （加色混合）—— pts = `{{x,y},{x,y},...}`（至少 3 点才画）
- `ctx:text(x, y, text, size, cr, cg, cb, alpha)`（排版盒左上角锚）/
  `ctx:text_centered(x, y, text, size, cr, cg, cb, alpha)`（几何中心锚）
- `ctx:layer(name)`：把**后续所有**指令换层；name = `"base"`（垫底先画）/ `"normal"`（默认）/
  `"top"`（盖顶后画）；破坏性擦除（`clear_circle`）必须垫底。
- `ctx:clear_circle(x, y, r)`：把圆内像素挖透明（打洞）
- `ctx:glow(x, y, r, cr, cg, cb, alpha)`（三层辉光）、`ctx:radial(x, y, r, cr, cg, cb, alpha)`
  （径向渐变）、`ctx:radial_stops(x, y, r, stops)`（多段径向渐变；
  stops=`{{offset=0,r=..,g=..,b=..,a=..},...}`，至少 2 段）、
  `ctx:diamond(x, y, size, cr, cg, cb, alpha)`、
  `ctx:diamond_rot(x, y, size, angle, cr, cg, cb, alpha)`、`ctx:plus_circle(x, y, r, cr, cg, cb, alpha)`、
  `ctx:image(x, y, scale, alpha)`（宿主注入的悬浮标位图；(x,y)=中心，等比缩放）
- `ctx:backdrop_circle(x, y, r, mode, zoom, cr, cg, cb, alpha) -> bool`：**真桌面采样**。
  `mode="magnify"` = 放大镜（源区半径 r/zoom，zoom 1–4）；`mode="difference"` = 逐通道
  `|源−(cr,cg,cb)|`（反色球）；`alpha` 与其它颜色同口径（0–255）。返回 false = 抓屏不可用，
  脚本应退回静态外观。★ 它在跑时覆盖层不进系统截图/录屏（排除自身，防镜片无限套娃）。

## 参数 schema（schema() 返回数组，每项一个字段）
`{ key="", label="", type="", default=…, … }`，type 取值：
`float`（min/max/step）、`int`（整数）、`bool`、`color`（#RRGGBB[AA]，默认带 alpha；
`alpha=false` 关闭）、`choice`（`choices={"a","b"}`，可选 `labels={"中文"}`）、`str`（文本）、
`hotkey`（组合键录制；只有 `scripts/` 独立脚本会当全局热键，特效/贴图脚本只存键位串）、
`sound`（宿主扫描音效目录）、`folder`、`file`（音频文件浏览）、
`image`（**只是路径框 + UI 占位，宿主不会自动加载或绘制**；要画图片用悬浮标内置
`ctx:image` 与悬浮标「PNG 图片」参数，别指望 `image` 参数自己出现在画面里）。
`schema` 声明的 `default` 在**交棒给脚本那一刻**合并：声明过的键一定存在，用户显式填的
`false` / `0` / 空串原样交；`int` 交整数。颜色只有 `#RRGGBB` 与 `#RRGGBBAA` 两种写法
（没有 `#AARRGGBB`）。参数保存即热更新。

## 扩展 API（userdata `ext`，所有脚本可用；冒号调用）
★ 阻塞类（HTTP / 下载 / 外部程序 / 模态窗）只能在 `run` 模型（工作线程）里调；
`draw` 逐帧跑在 UI 线程，宿主会拒绝，避免冻住屏幕。
- 对话框 / 窗口：
  - `ext:result(text)`：可选中复制的文本窗（记事本式，可改后复制）。
  - `ext:input(title, default) -> string | nil`：多行输入窗；确定=文本，取消/Esc=nil。
  - `ext:chat_window(url, model, key, sys)`：原生 AI 多轮对话窗；Ctrl+Enter 发送、Esc 关窗；
    HTTP 在窗口线程跑，阻塞到关窗。会话保存在 `<程序目录>/data/ai_chat/history.json`，
    **关窗/重启后自动恢复，点「清除」才清空**（只存 user/assistant 消息，不存 API Key）。
- 文件 / 进程 / 目录：
  - `ext:proc(opts) -> table | nil, err`：起脚本目录内的 `.exe`（绝对路径、`..`、`.dll/.bat` 拒绝），
    等它跑完；`opts={exe, args?, cwd?, timeout_ms?, ansi?}`，返回
    `{code, stdout, stderr, timed_out, truncated, elapsed_ms}`；默认 30s、上限 120s。
  - `ext:script_dir()` / `ext:tmpdir()` / `ext:data_dir()`：脚本目录 / 临时目录 /
    持久私有目录 `<程序目录>/data/lua/<id>/`（绝对路径，按需创建）。
  - `ext:read_file(path)` / `ext:write_file(path, data)`：任意路径读写；读上限 64 MiB，
    写后回读核长度；`write_file` 父目录自动建。
  - `ext:load_image(path) -> ExtImage | nil, err`：WIC 解码 PNG/JPEG/BMP/GIF/TIFF
    （WebP 看系统），原尺寸、保 alpha；128 MB / 64 MP 上限。
  - `ext:set_image(src) -> true | nil, err`：把**眼前这张贴图**换成新图（ExtImage 或路径）。
    只换视图、不写盘、不动出厂原图；像素变过后右键出现「恢复原图」。没有贴图上下文 ⇒
    nil + 原因；逐帧脚本里排到下一次派发才生效。
  - `ext:unzip(zip_path, dest_dir) -> int | nil, err`：解压 zip，拒绝路径逃逸/加密/超限，
    返回文件数。
  - `ext:download(url, path, headers?) -> int | nil, err`：流式下载（先 `.partial` 再原子改名），
    上限 512 MB；阻塞。
- 对话框选路径：
  - `ext:open_file(kind?, start_dir?) -> string | nil | nil, err`：原生打开对话框；kind =
    any/image/audio/gif/mp4（只影响过滤器；未知档返回错误，不降级）。
  - `ext:save_file(name?, ext?, start_dir?) -> string | nil`：原生另存为；ext 收成前导
    字母数字（≤8 字，默认 txt）。
- 系统打开：
  - `ext:open_temp(bytes, ext) -> string | nil, err`：把字节写成临时文件并用默认程序打开；
    ext 只准光栅图（png/jpg/jpeg/gif/bmp/webp/tif/tiff/ico）。
  - `ext:open_url(url) -> true | nil, err`：默认浏览器打开；只准 http/https。
- 剪贴板：
  - `ext:clip_get() -> string | nil`：剪贴板文本。
  - `ext:clip_image() -> ExtImage | nil`：剪贴板位图（α 一律刷成 255，按抓屏语义）。
  - `ext:clip_set(text) -> true | 抛错`：写文本并立刻回读核对；会覆盖用户剪贴板，
    面向用户的脚本应做成可关的开关。
- 网络 / JSON / 日志 / 贴图：
  - `ext:http(method, url, headers, body?) -> {status:int, body:string}`：阻塞 HTTP（60s），
    GET/DELETE/POST/PUT；错误 status=0；只能在 run 模型里调。
  - `ext:json_encode(value) -> string` / `ext:json_decode(text) -> table | nil`。
  - `ext:log(msg)`：写运行日志。
  - `ext:get_image() -> ExtImage | nil`：当前贴图快照（仅贴图动作上下文有值）。

## ExtImage 与 ctx.image
只读字段 `.w` / `.h`；方法：
- `png_base64()`、`bytes()`（原始 RGBA，长度 w×h×4）、`pixel(x,y) -> r,g,b,a`（越界全 nil）；
- `save(path, quality?)`：按扩展名写 `.png`（无损）或 `.jpg/.jpeg`（quality 1–100，默认 90，
  透明合成白底）；父目录自动建；
- `crop(x,y,w,h)`：越界不钳制，返回 nil+原因；
- `rotate_cw90()` / `flip_h()` / `flip_v()`：返回**新图**，手里这张不动。
贴图右键触发的 image 脚本在 `run(ctx)` 里拿到 `ctx.image`（同 ExtImage）与 `ctx.hwnd`。
要让屏幕上的贴图变化，必须显式 `ext:set_image(结果)`。

## 文件访问 ctx.fs（相对脚本所在目录，只读）
`ctx.fs:read(path) -> string | nil`、`ctx.fs:read_bytes(path)`、`ctx.fs:exists(path)`、
`ctx.fs:list(path) -> 表`。`../` 与绝对路径一律 nil（越界拒绝，防手滑，不是安全沙箱）。

## 回调签名与返回值
- 完整签名（多余的尾部实参可以不接，要用参数就得按序接住）：
  `init()`、`on_move(x, y, t, params)`、`step(dt, t, params)`、
  `on_press(x, y, t, params)`、`on_mouse_down(button, x, y, params)`、
  `on_mouse_up(button, x, y, params)`、`on_wheel(delta, horizontal, x, y, params)`、
  `draw(ctx, params)`、`on_key(key, mods, repeated, params)`、`run(ctx, params)`。
  `t` = 秒；`params` = 参数表（同时也写进全局 `_params`）。只写老名 `on_click` 也会按
  `on_press` 兜底。
- `init()` 的返回值被忽略；每实例状态直接用脚本自己的全局变量（每实例一份独立环境）。
- `step` 的返回值当前被忽略：淡出/老化自己拿 `t` 对时间戳算，到点把元素从状态表删掉。
- `draw(ctx, params)` 每帧调用，age=0 的帧也会画（出生帧必须画）；返回数字 n>0 =
  「n 毫秒后再来一帧」（悬浮标静止续帧）；不返回 = 不要额外帧。拖尾不看返回值——
  只有继续产出绘图指令才续帧。
- `on_mouse_down(button, x, y, params)`：全部宿主（优先于 `on_press`）；button 取值
  `"left"/"right"/"middle"/"x1"/"x2"`。★ 参数顺序与 `on_press(x,y,t)` **刻意不同**。
- `on_mouse_up(button, x, y, params)`：全部宿主；按住态视觉用。
- `on_wheel(delta, horizontal, x, y, params)`：复合/拖尾宿主；delta 一格 ±120（正=上/右）；
  只有脚本声明它，钩子才转发普通滚轮。
- `on_key(key, mods, repeated, params)`：复合脚本专属；key = 键名，
  mods = `{ctrl=bool, alt=bool, shift=bool, win=bool}`；返回值不被解释，发声要调 `play_sound()`。
- 回调容错：除 `schema` / `init` 外，缺失的回调一律静默跳过（不报错、不 panic）。

## 常见坑
- Lua 5.4：没有 `math.atan2`（用 `math.atan(y, x)`）；整除是 `//`。
- 颜色分量必须 0..255（不是 0..1）；alpha 也是 0..255，`math.floor` 后再传。
- 点击特效实例出生即 active，`on_press(x, y)` 里不要等下一次 move。
- 特效淡出靠自己在 step/draw 里用 `elapsed` 计算透明度画到 0，并把过期元素从状态表删掉。
- 大文本/长循环会卡渲染帧：脚本每帧预算以毫秒计，别在 draw 里做 IO。
- 在线包是 `<id>/` 文件夹；单文件脚本直接放角色目录即可。安装后约 250 ms 自动出卡，
  不要教用户重启程序。

## 完整示例 1：拖尾特效（放进 assets/lua/MouseTrail/，保存即热加载）
```lua
effect_name = "泡泡拖尾"
description = "鼠标划过时冒出上浮、渐隐的圆圈泡泡"

function schema()
  return {
    { key = "size",  label = "泡泡大小", type = "float", min = 2,   max = 30, step = 1,   default = 10 },
    { key = "fade",  label = "存活秒数", type = "float", min = 0.3, max = 3,  step = 0.1, default = 1.2 },
    { key = "color", label = "颜色",     type = "color", alpha = true, default = "#7FD4FFCC" },
  }
end

bubbles = {}   -- 实例状态用全局变量：每个实例一份独立环境

function init()
  bubbles = {}
end

function on_move(x, y, t, params)   -- 每个鼠标采样点调一次
  bubbles[#bubbles + 1] = { x = x, y = y, born = t,
                            vx = rng(-20, 20), vy = rng(-70, -30), r = rng(0.5, 1.0) }
end

function step(dt, t, params)   -- 老化放 step：鼠标停住也照常消散
  local keep = {}
  for _, b in ipairs(bubbles) do
    if t - b.born < (params.fade or 1.2) then
      b.x, b.y = b.x + b.vx * dt, b.y + b.vy * dt
      keep[#keep + 1] = b
    end
  end
  bubbles = keep
end

function draw(ctx, params)
  local cr, cg, cb, ca = hex_to_rgb(params.color or "#7FD4FFCC")
  local fade = params.fade or 1.2
  for _, b in ipairs(bubbles) do
    local k = 1.0 - (elapsed - b.born) / fade   -- 1 → 0 线性淡出
    if k > 0 then
      ctx:circle(b.x, b.y, (params.size or 10) * b.r,
                 cr, cg, cb, math.floor(ca * k))   -- 实心圆；描边改用 ctx:ring
    end
  end
end
```

## 完整示例 2：复合脚本（放进 assets/lua/scripts/；on_mouse_down / on_key 只有这个目录收得到）
```lua
name = "中键波纹"
description = "中键点击处画一圈外扩渐隐的波纹"

function schema()
  return {
    { key = "color", label = "颜色", type = "color", alpha = true, default = "#FFAA33" },

  }
end

function on_mouse_down(button, x, y, params)   -- ★ 参数顺序：先 button 后坐标（与 on_press 不同）

    rings[#rings + 1] = { x = x, y = y, born = elapsed }   -- 此刻的时间读全局 elapsed
  end
end

function step(dt, t, params)
  local keep = {}
  for _, r in ipairs(rings) do
    if t - r.born < (params.life or 0.6) then keep[#keep + 1] = r end
  end
  rings = keep
end

function draw(ctx, params)
  local cr, cg, cb, ca = hex_to_rgb(params.color or "#FFAA33")
  for _, r in ipairs(rings) do
    local k = (elapsed - r.born) / (params.life or 0.6)   -- 0 → 1
    if k >= 0 and k < 1 then
      ctx:ring(r.x, r.y, 6 + 44 * k, 3 * (1 - k) + 1, cr, cg, cb, math.floor(ca * (1 - k)))
    end
  end
```

## 完整示例 3：悬浮标（HoverDot）——指针静止超过 N 秒后显示光圈
```lua
effect_name = "悬停计时圈"
description = "指针静止超过设定时间后显示光圈；移动即消失"

function schema()
  return {
    { key = "delay",  label = "静止秒数", type = "float", min = 0.2, max = 10, step = 0.1, default = 1.0 },
    { key = "radius", label = "半径",     type = "float", min = 4,   max = 80, step = 1,   default = 18 },
    { key = "color",  label = "颜色",     type = "color", alpha = true, default = "#4FC3F7CC" },
  }
end

local last_move_ms = 0
local still_ms = 0

function init()
  last_move_ms = wall_ms   -- ★ init 没有 params：这里不要读 params
  still_ms = 0
end

function on_move(x, y, t, params)
  last_move_ms = wall_ms
  still_ms = 0
end

function step(dt, t, params)
  still_ms = wall_ms - last_move_ms
end

function draw(ctx, params)
  local need = (params.delay or 1.0) * 1000
  if still_ms >= need then
    local cr, cg, cb, ca = hex_to_rgb(params.color or "#4FC3F7CC")
    local k = math.min((still_ms - need) / 250, 1)   -- 0 → 1 快速淡入
    ctx:circle(cursor_x, cursor_y, params.radius or 18,
               cr, cg, cb, math.floor(ca * k))
  end
  return 100   -- ★ 关键：始终续帧；不返回就收不到“静止后”的下一帧
end
```

> 为什么必须 `return 100`：悬浮标只在有帧需求时被驱动；指针静止后若不续帧，`still_ms`
> 永远不会继续增长，效果就“完全没出现”。代价是效果启用期间约每 100 ms 一帧——这是
> “检测静止”本身的开销，不要写成每帧都重绘的复杂效果。

## 虚拟键盘方案 JSON（assets/VirtualKeyboards/<方案名>.json，丢进去即出现在面板「虚拟键盘」下拉）
一个文件即一套方案，五块都可省略：
- 几何：`"name"` 显示名；`"base_layout": "<内置方案id>"` 引用出厂几何（**纯样式方案**就用
  这个，不带 rows）；`"rows": [ { "keys": [ {...} ] } ]` 自带几何（w 单位 = u = 一个标准键）。
- 每键字段（`rows[].keys[]`）：`code`（三种写法：单字符 `"q"`、枚举名 `"Esc"`/`"LShift"`、
  带编号 `"F5"`/`"Num3"`；空格写 `"Space"`）、`text`（常态图例，省略按 code 派生）、
  `shift_text`（Shift 图例，省略 = text）、`w` / `h` / `pad`、`caps`（字母键写 true，
  CapsLock 开时才变色）、`style`（引用 styles 表）、`radius`（单键圆角）。
- `defaults`（外观默认）：`font_size` / `opacity` / `corner_radius` / `scale` /
  `key_size`（标准键边长 px）/ `gap`（键间空隙 px）/ `hold`（按下高亮保持秒）。
- `styles` 命名样式表（CSS 思路），每项可有：`label` / `fill` / `text` / `border` /
  `press`（**本样式**按下色，双色方案靠它）/ `radius` / `side`（侧壁色 #RRGGBBAA）/
  `depth`（侧壁厚度 px，缺省 3）。立体键帽 = 本体正下方 depth px 垫一颗 side 色键帽、
  底边露出一圈；按下时本体坐进侧壁，即"按压物理感"，无需另设按下位移。
- `state_styles`：`"pressed": { "fill": …, "text": … }` 全局按下态（样式级 press 优先于它）。
- `keys` 逐键覆盖表：键 = 规范化键名（`"CharQ"` / `"SymMinus"` / `"Num1"` / `"Backspace"`…），
  值可有 `text` / `shiftText` / `style` / `radius`。
- `controls`（可选）面板控件清单，每项：`id`（缺省=bind）/ `label`（缺省按 bind 猜中文名）/
  `bind` / `type`（`color` / `range` / `bool`，缺省按 bind 猜）/ `min` / `max` / `step` /
  `decimals` / `default`。`bind` 路径语法：`defaults.fontSize` / `defaults.opacity` /
  `defaults.keySize` / `defaults.gap` / `defaults.hold` / `defaults.cornerRadius` / `defaults.scale` /
  `base.fill|press|border|text`（四个兜底色）/ `pressed.fill|text` /
  `styles.<样式名>.fill|text|border|press|radius|side|depth` / `keys.<键名>.radius`。
  没写 controls 时代码自动补齐预设项 + 每个命名样式的颜色（"看得见改不了"不会发生）。
- 分层优先级（低→高）：内置默认 → defaults → styles → 几何逐键 → keys 覆盖表 → 面板实时调整。
  ★ 鼠标穿透 / 总在最上 / 全屏避让是全局行为，方案干预不了。

## 生成脚本前自检（逐条对照，错一条就会“完全没效果”）
1. `ctx:*` 只在 `draw(ctx, params)` 里调用；`step` / `init` 里没有 `ctx`。
2. 没有使用 `os.*` / `io.*` / `debug` / `coroutine` / `utf8`；时间只用 `wall_ms` / `local_ms`。
3. `init()` 无参数、没有读 `params`（默认值在 schema 里声明，宿主会合并）。
4. 悬浮标 / 静止检测：`draw` 返回正整数毫秒续帧，静止时长用 `wall_ms` 算，不用 `elapsed`。
5. `hex_to_rgb` 接 4 个返回值；`hsv_to_rgb` 只接 3 个；颜色分量是 0–255 整数。
6. `effect_name` / `schema` / 目标目录匹配（HoverDot → `assets/lua/HoverDot/`）。
7. `draw` 里不做 IO / 网络 / 外部程序 / 长循环；阻塞能力只在 `run` 模型里用。
8. 给出完整文件内容与保存路径，不要只给片段。
