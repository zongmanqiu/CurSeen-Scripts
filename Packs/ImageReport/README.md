# 图片体检（CurSeen Lua 扩展包）

对当前贴图做一次信息体检，结果直接进 CurSeen 的文本窗：

```markdown
## 基本信息
- 尺寸：1920 × 1080（2073600 像素，横向）
- 比例：16:9 = 1.778  （≈ 16:9）
## 透明度
…
## 颜色
…
## 主色板（8 色）
1. #AABBCC — 23.4%
…
## 对比度
…
## 清晰度
…
```

- 六个分组：基本信息 / 透明度 / 颜色 / 主色板 / 对比度 / 清晰度。
- 大图按面积步长采样，每段都写明采样点数；数字可复算。
- 主色板用中位切分（确定性），对比度按 WCAG 2.1，清晰度按拉普拉斯方差。
- 结果窗是纯文本（不渲染 Markdown），复制后可直接粘进 Markdown 文档。

## 安装

在 CurSeen「设置 → 官方资源下载」里刷新并安装；脚本会装到
`assets/lua/scripts/1.image_report.lua`。也可以手动把本目录的 `.lua` 放进
`assets/lua/scripts/`。

## 用法

贴图上点右键 → 脚本 → 图片体检；没有贴图时脚本会改用剪贴板里的截图。
脚本页可设「主色板色数」与「快捷键」。
