# OCR 文字识别 历史

## 0.2.1（2026-10-30）

- 说明补全：明确 OCR 文字识别、贴图/剪贴板截图、默认复制与官方工具随包。
- 安装包补文档夹（LICENSE / README / HISTORY），发行日期更新为 2026-10-30。


## 0.2.0（2026-10-30）

- 改为**官方工具随包**：安装后 OCR 引擎与模型一起落在 `scripts/ocr_tool/`，用户不需要
  自己准备任何 dll / exe / onnx 文件。
- 工具源码、构建脚本与上游版本锁在仓库 `tools/ocr/`；编译产物不进源码仓库。
- 脚本 `requires` 增加角度分类模型；工具路径改为 `./ocr_tool/CurSeenOcr.exe`。

## 0.1.0（2026-10-30）

- 首个在线发布：外置离线 OCR（识别贴图 / 剪贴板截图），结果默认复制到剪贴板。
- 与 CurSeen 内置版内容一致；作为在线包发布，便于独立升级与卸载。
